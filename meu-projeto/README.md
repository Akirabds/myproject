# Meu Projeto

Este é um projeto de exemplo que demonstra a estrutura básica de uma aplicação utilizando TypeScript e Express.

## Estrutura do Projeto

```
meu-projeto
├── src
│   ├── app.ts                # Ponto de entrada da aplicação
│   ├── controllers           # Contém os controladores da aplicação
│   │   └── index.ts          # Controlador principal
│   ├── routes                # Define as rotas da aplicação
│   │   └── index.ts          # Configuração das rotas
│   ├── services              # Contém a lógica de negócios
│   │   └── index.ts          # Serviços da aplicação
│   └── types                 # Tipos e interfaces
│       └── index.ts          # Tipos personalizados
├── package.json              # Configuração do npm
├── tsconfig.json             # Configuração do TypeScript
└── README.md                 # Documentação do projeto
```

## Instalação

Para instalar as dependências do projeto, execute:

```
npm install
```

## Execução

Para iniciar a aplicação, utilize o seguinte comando:

```
npm start
```
